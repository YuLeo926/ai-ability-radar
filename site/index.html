Windows 本地工具 · v0.2 预览

把主观怀疑变成可复核的任务记录

所谓“降智检测”在这里仅指：用固定、客观评分的快速题包记录一次表现，并在条件一致时查看历史。 它能说明这次题包通过了什么，不能测量 IQ、解释模型内部变化，也不生成“降智”或退化裁决与置信度。

下载 Windows 预览版 查看源代码

两条独立测试线

客户端复制粘贴与自动 CLI 测试不混比

ChatGPT / Claude 客户端

在全新对话中逐题复制 8 道快速题，再把原始回答粘回应用。题包包含 3 道指令遵循、 3 道逻辑与 2 道代码审查题；人工复制粘贴时间计入本轨时长。

Codex CLI / Claude Code

在各自临时目录完成 2 个原创 JavaScript 微型项目，并由本地允许列表验证器评分。 仅 CLI 任务要求 Node.js 22/24 LTS；进程与验证器时间合并记录。

结果能怎么读

类别等权分数只描述当前题包。目标、报告模型、推理档位、题包、系统、工具版本和 clean/resumed 状态不同都会分开存储；两条测试线的时长不能互相比较。

谁支付测试费用

运行者承担自己的订阅用量

普通 GitHub CI 只运行假 CLI，不消耗任何 AI 订阅。个人电脑上的真实 CLI 测试会把用量 计入运行者自己的账号；维护者不提供共享凭据，也不代付。GitHub 托管 runner 的计费则 按仓库所有者的 GitHub 计划执行，与 AI 订阅分开。

本地优先

应用不收凭据，也没有默认上传

  • 应用没有遥测、后台上传、分析、广告、Cookie 或公共排行榜。
  • 应用不读取或保存 ChatGPT、Claude、Codex 或 GitHub 登录凭据。
  • 原始回答、CLI 日志和历史默认保存在本机；公开报告使用字段允许列表。
  • 真实测试的提示词与临时代码仍会发送给所选 AI 服务，并受该服务政策约束。
  • 完整本地备份含原文且不加密，导出前应用会再次明确提醒。
