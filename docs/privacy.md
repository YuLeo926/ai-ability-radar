# v0.2 隐私说明

## 应用收集什么

应用没有遥测、分析 SDK、后台上传端点、广告或公共排行榜。它不读取或保存 ChatGPT、Claude、
Codex 或 GitHub 登录凭据。用户填写的目标、报告模型、推理档位、客观分数、环境版本、原始回答和
CLI 日志用于本地历史与恢复；默认都留在这台电脑上。

这不等于“测试过程没有网络流量”。客户端测试由用户把提示词发送到所选 AI 服务；真实 CLI 测试
会把提示词与临时基准代码发送给所选 AI 提供商。被调用的 CLI 与提供商可以按自己的政策保存日志、
保留内容并启用自己的遥测。应用没有能力覆盖这些政策。

## 模型辅助识别

模型辅助识别只读取受支持客户端窗口中可访问的选择器名称。客户端没有公开当前选择器，或只读扫描
在限定时间内未完成时，应用会回退到手动填写；这两种结果都不表示自动识别成功。应用不会为识别
截图、读取对话正文、点击客户端、键入内容、发送消息，或额外调用模型、提供商 CLI 与订阅。

自动识别结果只用于预填，模型和推理档位仍由用户检查并确认。手动填写后创建的运行会记录
`manual` / `user_confirmed`，不会伪装成客户端自动报告的结果。

## 本地位置与内容

Windows 上使用 Tauri 的应用数据目录：`%APPDATA%\com.aiability.radar`。其中
`ability-radar.db` 保存结构化历史，`artifacts` 保存原始回答、日志和临时任务证据。路径中的
`%APPDATA%` 由当前 Windows 账号解析；文档不展示真实用户名。

公开 HTML 报告采用结构字段允许列表，排除原始回答、日志、用户名、设备名与绝对路径。完整本地备份
则包含 SQLite 快照和原始 artifacts，未加密；应用会在导出前要求明确确认。用户应自行选择受保护的
保存位置，并了解外部备份工具可能继续复制该文件。

## 保留与删除

原始数据默认永久保留，用户可选择受支持的本地保留策略，也可以删除单次运行、目标历史或原始证据。
应用通过文件系统正常删除文件；SQLite 启用 `secure_delete`，完整删除一条运行后会请求
`wal_checkpoint(TRUNCATE)` 截断 WAL（数据库正忙时 SQLite 可能延后回收）。

这不是取证擦除。SSD 的闪存转换层、文件系统快照、杀毒软件隔离区和外部备份都可能保留可恢复副本。
若设备处置或合规要求需要不可恢复删除，应使用操作系统、磁盘加密和备份系统提供的专门流程。

## 运行隔离与隐私边界

每个 CLI 任务使用独立目录；Codex 使用 `workspace-write`，Claude 只允许 Read/Edit/Write 工具并以
`dontAsk` 非交互策略运行；固定时间/turn 上限和验证器允许列表降低意外越界。但这不是容器、VM
（虚拟机）或恶意代码 sandbox（沙箱）。v0.5 计划把更强的 WSL/容器隔离作为真实仓库与 DeepSWE
的前置门禁；v0.2 没有这些能力。

更多威胁边界见[安全说明](security.md)，需要清理数据时见[故障排查](troubleshooting.md)。
