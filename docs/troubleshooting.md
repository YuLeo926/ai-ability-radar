# v0.2 故障排查

报告问题前先记录应用版本、Windows 版本、目标类型、题包版本和**脱敏错误类别**。不要粘贴原始回答、
完整 CLI 日志、令牌、登录输出、用户名、设备名或绝对路径。

## 客户端模型辅助识别回退

进入 ChatGPT 或 Claude 客户端的手动设置页时，应用会自动执行一次本地只读识别。当前 Codex
客户端可能返回 `not_exposed` 或 `timed_out`：

- `not_exposed` 显示“客户端没有公开当前选择，可手动填写”；
- `timed_out` 显示“读取客户端选择超时，可手动填写”。

两者都不是自动识别成功，都会保留手动填写。模型输入框和推理档位控件仍可编辑；必填内容没有完成
并确认前，“开始快速体检”保持禁用。“重新识别”只会重新执行同一只读扫描，不会点击客户端、键入
内容、发送消息，或调用模型、提供商 CLI 与订阅。

本机本轮源码验收实际返回 `timed_out`，并观察到“重新识别”先显示
“正在读取客户端可见选择器…”，随后再次回退到“读取客户端选择超时，可手动填写”。验收没有填写
模型或启动体检；手动运行保存 `manual` / `user_confirmed` 的行为由自动测试覆盖，不应据此理解为
本轮已在真实客户端启动运行。

## CLI 未找到

Windows 上已确认的一种症状是：CLI 通过 npm 安装，PowerShell 能找到 `codex`，但 npm 生成的
`codex.cmd` shim 没有被旧版检测路径识别。先在新开的 PowerShell 中运行以下只读检查：

```powershell
Get-Command codex -All
where.exe codex
codex.cmd --version
```

这些命令只检查命令解析和本地版本；`--version` 不会发送模型请求，也不会消耗模型订阅用量。
“未检测到受支持入口”表示 PATH 中没有通过安全审核的安装；
“入口不可访问”表示发现了候选但 Windows 拒绝启动；
“版本检测失败”表示候选可以启动但没有通过只读版本探测。
重新检测不会调用模型，也不会消耗订阅额度。

不要为排错运行真实提示词。确认 CLI 路径和版本正常后，在应用的编程 CLI 区域点击
“重新检测 CLI”。如果变化发生在应用启动时已经继承的 PATH 目录内，可以立即重新检测；如果安装程序
新增了 User 或 Machine PATH 目录，请先重启应用，再点击“重新检测 CLI”。应用不会替你安装真实 CLI。

## 未登录或登录失效

在应用之外按所选 CLI 的官方流程登录，再回到应用重新检查就绪状态。不要把登录输出或 token 发到
issue。应用不会读取认证文件，也不会保存凭据；CLI 本身仍会按自己的认证与遥测政策工作。

## Node.js 版本不支持

CLI 题目的本地验证器只支持 Node.js 22/24 LTS。运行 `node --version`，确认主版本是 22 或 24，
且 `node.exe` 来自预期安装。客户端复制粘贴题不需要 Node.js。

## 配额或 agent budget

提供商配额、速率限制或订阅用量不足通常属于基础设施无效，修复账号状态后重新运行。受控超时、达到
turn 上限或输出预算耗尽属于 agent-budget failure，会按既定预算内未完成计分；不要把两类错误合并。
真实 CLI 用量始终计入运行者自己的订阅。

## 网络错误

应用没有自己的上传端点，但真实 CLI 必须连接所选 AI 提供商。检查系统时间、代理、防火墙、DNS 和
提供商状态。不要为了排错关闭企业安全控制；如果网络策略不允许该服务，请停止真实测试。

## SmartScreen 提示

v0.2.2 目前是候选/待发布构建，公开下载尚未开放。只有 clean Windows 10/11 x64 验收通过并创建
公开发布后，才从仓库 Releases 下载；届时应在继续前用 `Get-FileHash -Algorithm SHA256` 对照
`SHA256SUMS.txt`。安装程序和免安装 ZIP 均未签名，SmartScreen 可能显示“未知发布者”；如果校验值
不同，不要运行该文件。

## 中断与恢复

应用启动时会把遗留的 running 记录标为 interrupted。可恢复运行会重新核对目标、题包哈希、环境版本
和已有 checkpoint；无法通过核对时会拒绝恢复，避免把不同条件混为同一结果。恢复状态与 clean 运行
存入不同历史系列。若取消仍在处理中，请等待进程终止，不要手工改动 artifacts。

## 本地数据位置

Windows 数据位于 `%APPDATA%\com.aiability.radar`，包括 `ability-radar.db` 和 `artifacts`。
关闭应用后再进行管理员要求的备份或设备维护。优先使用应用内删除功能；它执行正常文件删除和 SQLite
清理，但不是取证擦除，SSD、快照、杀毒隔离区和外部备份仍可能保留副本。

## 仍然无法解决

使用 GitHub bug 表单，提供脱敏后的类别和版本信息。安全问题请改用根目录[安全政策](../SECURITY.md)
所述的私密 GitHub Security Advisory 流程。
